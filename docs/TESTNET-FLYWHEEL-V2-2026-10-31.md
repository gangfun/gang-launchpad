## V2 和 V1 的区别

只改了开盘后铸币的定价和暂停规则，其余（开盘前打新、卖回、开盘、保护期、税、持有人奖励、邀请）都跟 V1 一样。

| | V1 | V2 |
|---|---|---|
| 开盘后铸币的价格 | 取最高：现价、本区块起始价、上一区块起始价的 99%、近期高点的 99%、30 分钟均价的 99% | 现价和本区块起始价中较高的 |
| 暂停 | 比 30 分钟均价或近期高点低 10% 以上（近期高点每分钟衰减 0.5%） | 只有 dev 打开护栏时才暂停：比均价低 15% / 20% / 30% 以上（均价窗口 15 或 30 分钟） |
| 比池子价高 10% 以上 | 拒绝 | 拒绝（只会发生在同一区块内有人砸盘之后） |
| 开了开盘后铸币时 | 基础配额 5–100、邀请加成 0–3 | 基础配额 5–10、邀请加成 0–1、必须有 Agent ID 门槛 |
| 线性阶梯价 | 从第 0 份开始计数 | 从开盘后计数（第 10,001 份是 1 倍） |

新增视图 `postRulesOf(token) → (guardBps, twapWindow)`；`sales()` 的返回结构不变；`Created` 事件多了这两个字段。handler、代币合约和代币部署器的字节码跟 V1 完全一样。
