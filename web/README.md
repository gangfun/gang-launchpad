# gang.fun

Gang launchpad site: boards (new / hot / graduated), token pages with price chart, trades and holders, and the agent how-to. The header connects a Binance Wallet (extension or App QR) for `/me`. Curve buys still go through the agent CLI.

```bash
cp .env.example .env      # VITE_API_URL = indexer, VITE_LAUNCHPAD
npm install
npm run dev
```
